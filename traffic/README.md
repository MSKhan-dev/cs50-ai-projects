# Traffic Sign Recognition

This project uses a Convolutional Neural Network (CNN) to classify traffic sign images.

## AI Concepts
- Neural Networks
- Convolutional Neural Networks (CNN)
- Image Classification
- Supervised Learning

## Dataset
The GTSRB (German Traffic Sign Recognition Benchmark) dataset is required to run this project.

⚠️ The dataset is **not included in this repository** because it is very large and exceeds GitHub file size limits.

You can download the dataset from the CS50 AI course resources:
https://cs50.harvard.edu/ai/projects/5/traffic/

After downloading, place the dataset inside the `traffic/gtsrb/` directory.

## How to Run
```bash
python traffic.py gtsrb
